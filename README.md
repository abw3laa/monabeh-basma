# منبّه البصمة — Fingerprint Reminder

تطبيق Android لإدارة التنبيهات والتذكيرات بواجهة عربية RTL، اعتمادًا على تصاميم Stitch الموجودة في مجلد التصميمات.

## الحالة الحالية
- المستودع أُنشئ فارغًا؛ هذا هو التأسيس الأول للمشروع.
- ملف `stitch_android_app_design.zip` هو تصدير لتصاميم HTML وصور معاينة، وليس مشروع Android قابلًا للبناء.
- سيتم تنفيذ التطبيق كتطبيق Android فعلي، ثم إضافة آلية فحص التحديثات والإشعار بها؛ لا يتم تثبيت التحديث دون موافقة المستخدم عبر واجهة Android.
- لا تُخزّن مفاتيح التوقيع أو كلمات المرور أو رموز الوصول داخل المستودع.

## المتطلبات المخططة
- واجهات عربية من اليمين إلى اليسار.
- إدارة التنبيهات والتذكيرات.
- صفحة «حول التطبيق» ومعلومات المطوّر وروابط التواصل.
- زر يدوي للبحث عن تحديثات.
- شاشة «ما الجديد؟» تظهر مرة واحدة بعد التثبيت/التحديث.
- إعدادات واضحة وإمكانية الوصول.
- بناء APK/Release والتحقق عبر GitHub Actions قبل إعلان أي إصدار.

## سير العمل
- `main` للنسخة المستقرة.
- التطوير على فروع مهام منفصلة.
- تشغيل الفحوصات والبناء قبل دمج أي تغيير.
