# منبّه البصمة — Fingerprint Reminder

تطبيق Android باللغة العربية لإدارة مواعيد البصمة، نافذة الموعد ذات الأيام الثلاثة، والتنبيهات المتكررة. مبني باستخدام Kotlin وAndroid SDK.

## الوظائف الحالية
- إنشاء موعد واختيار التكرار كل 28 يومًا أو أسبوعيًا.
- حفظ المواعيد محليًا على الجهاز.
- تنبيهات مسبقة وفي الأيام الأول والثاني والثالث من نافذة الموعد.
- سجل للمواعيد وتأكيد إتمام البصمة وإنشاء الموعد التالي.
- إعادة جدولة التنبيهات بعد إعادة تشغيل الهاتف.
- صفحات الرئيسية، المواعيد، السجل، الإعدادات، وحول التطبيق.
- شاشة «ما الجديد؟» تظهر مرة لكل إصدار.
- التحقق من GitHub Releases، تنزيل APK عند توفره، ثم طلب موافقة المستخدم من مثبت Android.

## البناء
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- JDK 17
- compileSdk 35
- minSdk 26

GitHub Actions يشغّل `gradle assembleDebug` على فروع التطوير وطلبات الدمج.

## ملاحظات مهمة
- التنبيهات الدقيقة تعتمد على أذونات وإعدادات أندرويد وقد تتأخر بسبب قيود البطارية والشركة المصنّعة.
- آلية التحديث تتطلب نشر GitHub Release وإرفاق ملف APK باسمه المنتهي بـ `.apk`. لا يتم تثبيت أي تحديث بصمت؛ يطلب Android موافقة المستخدم.
- ملفات التصميم المصدرية من Stitch محفوظة في ملف ZIP المرفق بالمحادثة، وهي مراجع واجهات وليست مشروع Android جاهزًا.
- لا تُحفظ مفاتيح التوقيع أو كلمات المرور أو رموز الوصول داخل المستودع.
